01

场地配置流程

范围:场地的新增、编辑、停用与开放 · 端:运营平台(基础配置)
① 新增 / 编辑场地
开始
进入「基础配置」列表
点击 新增场地 / 编辑
新增
填写场地信息名称*、楼栋*、楼层*、房间号*、容纳人数*、预订类型*、照片*、描述(不展示场地编号)
提交
后台自动生成场地编号
编辑
编号、状态反显不可编辑,仅可修改其余字段
修改并保存
必填项校验通过?
否
表单提示,停留在弹窗补充填写
是
保存成功,状态 = 开放中列表刷新,记录创建人/创建时间
结束
② 停用 / 开放场地
开始
列表点击「停用」/「开放」
停用时:存在已预订未签到的排期?
是
阻断停用,Toast 提示「场地名」存在已预订未签到的排期,不可停用
结束
否
二次确认弹窗 → 确认
状态变更为 停用 / 开放中停用后列表行置灰,操作列切换为「开放」
结束
02

场地排期流程

范围:排期的批量创建、删除与状态流转 · 端:运营平台(场地排期)
① 新增排期(按日 / 按周 / 按月批量)
开始
进入「场地排期」日视图 / 场地月历视图
点击「＋ 新增排期」
选择日期模式按日:选日期 · 按周:选星期 · 按月:选每月几号
添加排期时段(可多个)开始/结束时间下拉,30 分钟粒度,08:00–22:00
时段校验通过?结束时间 > 开始时间;多个时段不重叠
否
弹窗内提示,调整时段后重新提交
是
提交,批量生成排期
排期初始状态:可预订容量 = 场地容纳人数,已订 0/容纳人数
日视图 / 月历同步展示月历可点击日期查看日详情
结束
② 删除单个排期(月历 · 日详情弹窗)
开始
月历点击日期,打开日详情弹窗
排期未被预订 且 结束时间 > 当前时间?
是
展示「删除」按钮 → 二次确认
排期移除,日详情与月历刷新
结束
否
不提供删除入口已预订或已过期的排期不可删除
结束
③ 排期状态自动流转(无需人工干预)
可预订 ⇄ 已约满:订单占用/释放名额驱动,展示 预订人数/容纳人数;课程排课默认占满,直接进入已约满 · → 不可预订:排期结束时间早于当前时间,或所属场地停用(存在订单的排期不展示"不可预订")
03

场地预订流程

范围:订单的产生、名额占用、签到与取消 · 端:员工App / 居民App / 运营平台(仅查看)
① 下单与名额占用(无审批流,满足规则即下单成功)
开始
员工预订
员工 App 浏览排期下单
客户预订
居民 App 浏览排期下单
课程排课
活动管家在运营平台排课自动占用排期生成课程订单
预订规则校验① 当前时间在排期结束前 15 分钟内或已过期 → 不可订
② 排期被课程占用 → 不允许员工/客户预订
③ 员工+客户预订人数总和 ≤ 容纳人数
不满足
不可预订,App 端给出对应提示
结束
满足
下单成功,占用排期名额员工/客户:按预订人数累加 · 课程:默认占满
名额已占满?
是
排期状态 → 已约满
否
排期保持可预订继续接受订单
生成订单:未签到一个排期可关联多个订单
结束
② 签到 / 取消(App 端操作,后台仅查看)
订单:未签到
到场签到
用户在 App 端签到核销
订单 → 已签到
排期结束,订单完成
结束
取消订单
用户在 App 端取消
订单 → 已取消,释放名额
排期人数减少已约满的可回到可预订
结束
③ 后台侧(运营平台)
活动管家在「订单列表」按 Tab(未签到/已签到/已取消) 与筛选条件查看订单、查看详情抽屉(关联排期、预订信息、状态流转); 后台不提供签到、取消操作 —— 页面提示:如需取消订单或到场签到,请在 App 端进行相应操作
